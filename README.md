📊 Overview

The E-commerce Sales Report is a Power BI dashboard that provides a comprehensive analysis of sales performance across different product categories, regions, and payment modes. It enables businesses to monitor key performance indicators (KPIs), identify profit-driving products, and make data-driven decisions through interactive visualizations.

The dashboard combines Orders and Details datasets to deliver meaningful insights into customer orders, product performance, and profitability.

🎯 Objectives
Track Total Sales, Profit, and Quantity Sold
Analyze sales by Category, Sub-Category, and Region
Understand customer purchasing behavior through Payment Modes
Identify top-performing States, Cities, and Products
Enable data-driven business decisions using interactive dashboards
✨ Features
